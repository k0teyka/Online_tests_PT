# 👑 Онлайн-викторина "Какая ты принцесса Disney" (для показа перед спектаклем)

Интерактивный квиз с экраном для проектора, авто-генерацией QR-кода, адаптивным мобильным интерфейсом для зрителей и веб-панелью онлайн-редактирования вопросов.

---

## 🎯 Специфика использования перед спектаклем

Когда перед началом спектакля на большом экране проектора загорается QR-код:
1. **Сотни зрителей одновременно** достают телефоны и сканируют код за короткий промежуток (5–15 минут).
2. Мобильный интернет в залах театров часто бывает слабым или перегруженным.
3. Обычный слабый сервер с динамической базой данных может "упасть" от такого пикового наплыва (эффект всплеска трафика).

### 💡 Архитектурное решение в этом проекте:
* **Супер-легкий вес (Zero-dependency Jamstack)**: страница и скрипты весят считанные килобайты, загружаются за миллисекунды даже на слабом 3G/LTE.
* **Автономность**: может работать вообще без бэкенда через глобальный CDN (выдерживает десятки тысяч одновременных зрителей) либо через микросервер на Node.js.
* **Встроенный экран для проектора (`projector.html`)**: темная театральная тема, мерцающие сказочные частицы, крупный контрастный QR-код, таймер обратного отсчета до третьего звонка и кнопка F11 на весь экран.
* **Онлайн-редактор (`admin.html`)**: визуальное управление вопросами, вариантами ответов, баллами и карточками принцесс прямо через браузер с защитой по паролю.

## 🚀 Где развернуть: варианты дешевого и бесплатного хостинга

### Вариант 1: Бесплатный CDN-хостинг (Рекомендуется ⭐⭐⭐⭐⭐)
Идеально, так как не требует настройки серверов, держит любую нагрузку зрителей и стоит **0 ₽**:

1. **Cloudflare Pages / GitHub Pages / Vercel**:
   - **Стоимость**: 0 ₽ (Бесплатно навсегда).
   - **Нагрузка**: Выдерживает хоть 50 000 человек одновременно благодаря мировой сети кэширования Cloudflare/Vercel.
   - **Как развернуть**:
     1. Загрузите файлы папки на GitHub в новый репозиторий.
     2. Подключите репозиторий в **Cloudflare Pages** или **Vercel** (или включите GitHub Pages в настройках репозитория).
     3. Получите мгновенную ссылку вида `https://princess-quiz.pages.dev` или `https://твой-проект.vercel.app`.
   - **Редактирование**: редактируйте тест в `admin.html`, нажимайте «📥 Скачать questions.json» и заменяйте файл в проекте.

### Вариант 2: Дешевый виртуальный хостинг (Shared / VDS) в РФ (⭐⭐⭐⭐)
Если нужен российский хостинг с оплатой в рублях:

1. **Beget (Бегет)**:
   - **Тариф**: Cloud VPS с посуточной оплатой (~7-10 ₽ в день!) или обычный хостинг (~160-190 ₽/мес).
   - **Плюсы**: Бесплатный SSL-сертификат Let's Encrypt в 1 клик, привязка любого домена (например, `тест-театр.рф`), удобная файловая панель прямо в браузере (можно просто перетащить файлы мышкой).
2. **TimeWeb**:
   - От ~180-200 ₽/мес. Удобный веб-интерфейс, поддержка Node.js в 1 клик.
3. **Selectel / FirstVDS**:
   - Недорогие VDS от ~150-250 ₽/мес.

---

### Вариант 3: Локальный запуск в театре без интернета (⭐⭐⭐⭐⭐ для закрытых сетей)
Если в зрительном зале плохой мобильный интернет или вы хотите полную автономность:

1. Подключите ноутбук к местному роутеру театра по Wi-Fi или проводу.
2. Запустите встроенный сервер:
   ```bash
   node server.js
   ```
3. Сервер выведет в консоль локальный IP (например, `http://192.168.1.55:3000`).
4. Откройте на ноутбуке экран проектора: `http://localhost:3000/projector.html`, нажмите на ссылку внизу и укажите этот IP.
5. Зрители, подключившись к театральному Wi-Fi, мгновенно проходят тест даже при полном отсутствии внешнего интернета!

## 🛠️ Структура проекта

* `index.html` — Мобильный интерфейс теста для зрителей.
* `projector.html` — Полноэкранный кино-экран для проектора с динамическим QR-кодом и таймером обратного отсчета.
* `admin.html` — Веб-панель управления и онлайн-редактирования тестов (пароль по умолчанию: `admin123`).
* `questions.json` — Основная база данных вопросов и принцесс в формате JSON.
* `questions.js` — Резервная встроенная база на случай открытия офлайн.
* `quiz.js` — Движок викторины (подсчет очков, переходы, конфетти, шеринг).
* `qrcode.js` — Быстрый генератор четких SVG QR-кодов без внешних библиотек.
* `style.css` — Стильный сказочный адаптивный дизайн (Glassmorphism, градиенты, анимации).
* `server.js` — Автономный Node.js сервер с REST API `/api/quiz`.

## ⚙️ Как редактировать тесты онлайн

1. Откройте страницу `/admin.html` (в браузере).
2. Введите пароль администратора (по умолчанию: `admin123`).
3. Вкладка **«📋 Вопросы»**:
   - Редактируйте тексты вопросов и подсказок.
   - Добавляйте или удаляйте варианты ответов.
   - Настраивайте, какому персонажу и сколько баллов приносит каждый ответ.
   - Меняйте порядок вопросов стрелками ⬆️ / ⬇️ или дублируйте их.
4. Вкладка **«👑 Персонажи / Принцессы»**:
   - Меняйте имена, титулы, цитаты и описания.
   - Добавляйте новых персонажей под конкретную тематику спектакля.
5. Нажмите **«💾 Сохранить всё»**:
   - Данные сохранятся в памяти браузера, а при запущенном `server.js` — запишутся в `questions.json`.
   - Можно нажать **«📥 Скачать questions.json»**, чтобы сохранить копию.

## 🎬 Чек-лист в день спектакля

1. За 30–40 минут до начала откройте `projector.html` на ноутбуке, подключенном к проектору.
2. Проверьте, что QR-код ведет на ваш публичный домен теста (нажав на строку ссылки внизу экрана).
3. Просканируйте код со своего телефона и убедитесь, что тест открывается мгновенно.
4. Выберите на экране таймер (например, 10 или 15 минут) и нажмите **F11** (полный экран).
5. Наслаждайтесь реакцией зрителей в зале! 👑✨
