# 👑 Онлайн-викторина "Какая ты принцесса Disney"
### Архитектура: Vercel (Хостинг) + Supabase (Облачная БД и Картинки)

Современная серверлесс-викторина, оптимизированная под одновременный наплыв зрителей в зрительном зале перед спектаклем.

---

## 🚀 Как всё устроено:

1. **Vercel** раздает статический сайт на ультра-высокой скорости через мировой CDN (0 ₽, выдерживает десятки тысяч зрителей, дает короткую красивую ссылку для проектора).
2. **Supabase** хранит актуальный текст теста и картинки:
   - При изменении в админке данные сразу улетают в облако без коммитов в Git.
   - Загруженные картинки сохраняются в **Supabase Storage** (бакет `quiz-assets`) и получают постоянную публичную ссылку.
3. **Проектор (`projector.html`)**: показывает крупный контрастный QR-код и таймер обратного отсчета до спектакля.

---

## ⚡ Пошаговая настройка за 5 минут

### ШАГ 1. Настройка Supabase (Бесплатно, 2 минуты)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (можно войти через GitHub в 1 клик).
2. Нажмите **«New project»**, введите имя (например, `princess-quiz`), придумайте пароль базы данных и нажмите **«Create new project»**.
3. В левом меню откройте **«SQL Editor»** (значок терминала/таблицы `>_`).
4. Нажмите **«New query»**, скопируйте всё содержимое файла [`supabase-schema.sql`](supabase-schema.sql) и нажмите зеленую кнопку **«Run»**.
   *(Это создаст таблицу `quiz_state` и публичный бакет `quiz-assets` для картинок).*
5. Перейдите в **Project Settings** (шестеренка внизу слева) → **API**:
   - Скопируйте **Project URL** (вида `https://abcdefgh.supabase.co`).
   - Скопируйте **Project API Keys** → ключ **`anon` `public`** (длинная строка `eyJhbGci...`).

---

### ШАГ 2. Подключение Supabase в админке

1. Откройте в браузере [`admin.html`](admin.html).
2. Введите пароль администратора (по умолчанию: `admin123`).
3. Перейдите на вкладку **«⚙️ Экспорт / Импорт & Настройки»**.
4. В блоке **«⚡ Подключение к Supabase»** вставьте скопированные **Project URL** и **Anon Key**.
5. Нажмите **«🔌 Проверить и подключить Supabase»**.
6. Появится зеленый статус **«🟢 Supabase подключен»**.

> Теперь любые правки вопросов и загрузки картинок через админку автоматически и мгновенно сохраняются в облако!

---

### ШАГ 3. Размещение на Vercel (1 минута)

#### Вариант А: Через GitHub (Самый популярный)
1. Отправьте проект в свой GitHub-репозиторий:
   ```bash
   git add .
   git commit -m "Подключен Supabase и загрузка картинок"
   git push
   ```
2. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
3. Нажмите **«Add New...»** → **«Project»**.
4. Выберите ваш репозиторий и нажмите **«Deploy»**.
5. Через 15 секунд вы получите короткую красивую ссылку, например:
   `https://princess-quiz.vercel.app`

---

## 📷 Загрузка картинок через админ-панель

1. Откройте `admin.html`.
2. **Для принцесс (результатов)**:
   - Вкладка **«👑 Персонажи / Принцессы»**.
   - Нажмите кнопку **«Загрузить фото»** под именем принцессы и выберите файл с компьютера или телефона.
   - Картинка моментально загрузится в Supabase Storage и появится в карточке!
3. **Для вопросов**:
   - Вкладка **«📋 Вопросы»**.
   - Нажмите **«Выбрать картинку»** в блоке нужного вопроса.

---

## 📽️ Использование проектора в день спектакля

1. Подключите ноутбук к проектору на сцене.
2. Откройте страницу экрана проектора:  
   `https://ВАШ-ПРОЕКТ.vercel.app/projector.html`
3. Нажмите кнопку **⛶** в правом нижнем углу для перехода в полноэкранный режим.
4. Выберите на таймере нужное время (15, 10 или 5 минут).
5. Зрители сканируют QR-код и проходят тест со своих смартфонов! 👑✨
